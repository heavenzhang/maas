# v0.3 角色—任务—验收矩阵

本表用于原型交互验收，不代表真实组件已部署。参考流程来自 2026-10-02 核对的 [GPUStack 快速入门](https://docs.gpustack.ai/latest/quickstart/)、[GPUStack 与 New API 集成说明](https://docs.gpustack.ai/latest/integrations/integrate-with-newapi/)、[New API Key](https://docs.newapi.ai/en/docs/guide/feature-guide/user/token)与[用量日志](https://docs.newapi.ai/en/docs/guide/feature-guide/user/log)；SGLang 在本轮仅作为推理后端对象展示。

| 角色 | 任务 | 本轮状态 | 验收动作 | 真实联调门槛 |
| --- | --- | --- | --- | --- |
| 模型管理员 | 提交部署、观察就绪与对象映射 | 本地模拟可操作 | 提交后阶段变化，Ready 与最后一个步骤一致 | GPUStack 创建回执、实例健康、真实 GPU/模型 |
| 平台运营 | 将 Ready 部署发布成渠道 | 本地模拟可操作 | 未 Ready 时禁用发布；Ready 后发布成功 | New API 渠道创建、连通测试、内部鉴权 |
| 开发者 | 申请项目 Key，未批准时尝试调用 | 本地模拟可操作 | 审批前拒绝且无成功用量事件 | 统一身份、真实审批与 Key 签发回执 |
| 平台运营 | 审批或退回申请 | 本地模拟可操作 | 申请状态与 Key 状态可见，退回后能重新申请 | 摩度审批对象与 New API Key 的幂等映射 |
| 开发者 | 发起成功调用并追溯 | 本地模拟可操作 | 同一请求 ID 在调用详情和用量表中对应 | 真正的跨组件关联 ID、模型响应与日志采集 |
| 平台运营 / 开发者 | 主渠道故障与备份恢复 | 本地模拟可操作 | 备份开时恢复；备份关时失败且不计成功用量 | New API 路由规则、重试边界与一致性验证 |
| 平台运营 / 开发者 | 预算不足拒绝 | 本地模拟可操作 | 门户侧拒绝，成功用量与演示扣费均不增加 | 预算原子预占、撤销、正式账本与审计 |
| 所有角色 | 识别真实能力边界 | 界面可见 | 顶部四层边界、字段契约和控制台占位说明可见 | 实际部署及真实账号路径另行验收 |
