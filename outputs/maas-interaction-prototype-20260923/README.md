# MatrixCube MaaS · 集成交互原型

双击 [index.html](./index.html) 即可使用；无需安装依赖或连接后台。建议从「模型目录」选择 SGLang 私有模型，进入「调用工作台」体验请求，再到「用量事件」核对相同的 `request_id`。在「访问授权」可以另提一份 Key 申请、切换模拟审批视角并批准；浏览器会在本地保存演示状态，右上角可重置。

## 原型展示的集成关系

| 用户所见 | 拟整合组件及责任 | 当前实现状态 |
|---|---|---|
| 项目、Key 申请、审批、预算与正式账本 | MatrixCube 摩度业务控制面 | 仅前端本地状态模拟；尚无后端与真实账本 |
| API 入口与请求追踪 | APISIX 候选入口层 | 仅演示请求轨迹；未部署路由 |
| 统一模型目录、渠道和客户端 API | New API 候选模型网关 | 官方已有 SGLang 渠道；本原型未连接 New API |
| 私有文本模型服务 | KServe 生命周期管理候选 + SGLang 推理引擎 | KServe 适配、GPU 和 SGLang 实例均待 PoC |
| 训练和批任务 | Volcano 等调度候选 | 仅展示职责边界；未连接调度器 |

模型网关、入口和推理引擎仍需与同层候选比较，详见 [product-facts.md](./product-facts.md) 与飞书开发计划。本原型只展示优先验证路径，不表示架构已锁定。

## 验证与边界

- 桌面 1440×900、移动 390×844 的页面与交互回归已通过；截图在 [evidence](./evidence/) 目录。
- 已验证：目录筛选 → 选择 SGLang → 模拟调用 → 相同 request_id 出现在用量事件；Key 申请与审批；无匹配 Key 时回到授权页；浏览器无脚本错误。
- 模型回复由固定本地规则生成，token 数为界面演示估算；没有真实推理、网络调用、GPU 指标、供应商授权、价格、扣费或财务结算。
- 代码示例中的 `maas.example.invalid` 是不可访问的占位域名，`API_KEY` 是占位变量。请勿在本原型中输入真实凭据或敏感业务资料。

如需进入真实联调，下一步先固定 PoC 版本与硬件模型，部署 SGLang 端点和 New API SGLang 渠道，验证流式输出、工具调用、模型映射、Key 策略、错误恢复及用量事件，再评估 KServe 适配和 APISIX 是否必要。上述工作未包含在本交互原型的验收中。
